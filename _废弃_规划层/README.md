# ⛔ 废弃规划层（禁止用于写作）

归档时间：2026-10-29
归档原因：**这套规划从未落地为正文主线，且与已落地的正文冲突。**

## 目录里是什么

一套 **120 章制** 的早期规划（卷一 ch1-30 日常／卷二 ch31-60 深层／卷三 ch61-90 传递／卷四 ch91-120 终章），
配套 4 份卷纲 + 4 份章节表 + 1 份总纲。

## 为什么废弃

### 1. 与正文主线冲突（30 章标题不符）

正文 46 章实际走的是 **818 骨架线**（`lieque_reverse/04章节表/generated_all_818.json`），
不是这套 120 章规划。逐章核对结果：

| 正文 | 废弃层规划 | 冲突类型 |
|---|---|---|
| ch1 身份 | ch1 整理 | 标题 |
| ch2 迷雾 | ch2 罐子 | 标题 |
| ch3 回声 | ch3 加班 | 标题 |
| … | … | 共 30 章标题冲突 |
| ch25-46 顾家班线 | ch25-46 仓库/罐子/小陶/陈姐线 | **整条主线不同** |

废弃层描述的"仓库整理旧物→发现罐子→小陶→陈姐→回声传递"这条线，
在正文里只以**幻象/档案室场景**的形式零星出现（ch2 陈姐、ch38/39/41 小陶），
不是主线。

### 2. 章节表里是道诡原词的直搬

废弃层的 `04章节表/章节表_卷*.json` 与 `03卷纲/volume_*.json` 中，
角色名、事件、场景大量沿用《道诡异仙》原书结构（"仓库""罐子""整理旧物"式的
现实现代灵异包装），没有做"意同形不同"的重构，与《裂隙》已确立的三层世界
（阳间／档案室／深层）设定不匹配。

### 3. 卷划分依据失效

废弃层按"卷=连续章段"划分，但《裂隙》的实际推进是**三条线交错**：

- `modern` 现代人间线（档案室、大剧院仓库）
- `ancient` 古代异界线（临川镇、顾家班、云台寺）
- `archive` 档案室深层线（十二孔名单、碾磨机制）

818 骨架里三线交错推进，卷边界不再是自然的叙事分段。
