# 第四十八章 脱身

山门外那道石阶晒得发白。日头爬到头顶的时候，院子里的扫帚还在响——一下，一下，从东墙根扫到西墙根。

沈念坐在阶上，把签摊在膝盖上。

黄纸，两指长。上半行是他自己的笔迹，下半行那八个字端正得不像他写的：事成之日，自有记号。

折成两折，收进怀里。

昨夜在窖里待了一整夜，出来时手是热的，腿是软的。今天早上膝盖响了一声，手是凉的。

身子替他记了一夜。

签补全了，账就挂上去。挂上就走不掉。

走之前还有一桩没验。

守拙昨天下午说过一句：跛脚人来的时候，那味儿跟烧册子那天一样。这句话他在石阶上坐了一夜，没验过。

要验的是纸。

他怀里这张签，是从石屋那只木盘里裁的，签是他自己写的。那尊像身上，缝里的账纸片也是黄纸。守庙人塞给跛脚人的那包符，还是黄纸。三样若是一种纸，就是同一处发下来的，凑不出这个巧。

沈念转身往山门里走。

守庙人提着那盏不点的灯，在院子里给香炉续香。灰袍洗得发白。

沈念站在门柱后头看。

香炉里的灰是一层压一层的。他数了数，七层。

香灰落下来是尖的，落在灰面上会堆起一个小丘。每一层都是平的。

有人每天把灰面压一遍。压了七年。

沈念在门柱后头站了一会儿，转身走了。

去客店的路他昨夜走过一遍。出山门左手一条土坡，坡下十几户人家，客店是其中一间，门前挂着块褪了色的布幌。

伙计在门口劈柴。

「我的行李。」

伙计进去拎出一个包袱，一卷黄纸，一小截炭条。包袱扔在柜上，灰扬起来一层。

「跟着我来的那些人呢。」

「后院。板车停着，南塘班子的在屋里睡午觉。」伙计用柴刀背敲了敲木头，「跛脚那个不在，一早上山，说是去岔路口那个破庙取药。」

沈念记下这一句。

后院堆着柴，柴堆边上一层草，草上没有人。

灶房在西厢，矮，屋顶压着草。灶上一口锅，锅里坐着一只木盆，盆里是稀粥。锅边一只陶罐，罐里盐炒的豆，焦了边。案板上一把野菜，根粗叶细，洗过一遍，叶上还带泥。

他记下三样：粥稠得立勺，豆炒焦，菜只洗一遍。

送饭的时辰在巳时前后。灶是热的，锅沿一圈水渍干了——半个时辰前煮过一锅。

一个养得起灶的坛场，就得有人来吃。

沈念原路退回院子，在石阶上坐下。

等。

日头过了正南，灶房那边响起一块木板敲在门槛上的声音。敲三下。

山门外有人上来。

沈念站起身，往山门那边走，混进那三个人中间，脚步不快不慢。

一个老妇，一个背着孩子的妇人，一个挑担的汉子。

守在山门口的小道人让开身，一一验他们手里的东西。老妇的篮子里是鸡蛋，背孩子的妇人攥着三枚铜钱，挑担的担子里是一袋米。

小道人从袖里摸出一叠黄纸，在纸上各写一笔，写完卷起来，塞进木盘。木盘里已经有七八卷。

沈念站在后头等着。等道人写完最后一张，他把怀里那张签抽出来一半，捏在指间，斜对着日头。

道人手里那几张纸，透光，帘纹一条一条竖着，间距很匀。

跟他怀里这张一样。

第一样对上了。

求完了愿，几个人从院里出来，脸上松快些。下山的路跟上来时一样。

沈念跟在后头，肩上一条空口袋搭着，脚下踩得不紧不慢。

走出三里，他回头。

坡上没有人下来。

山门口那盏不点的灯还提着，守庙人还站在香炉边上。没有追。

守拙昨夜没拦他，今早也没拦。守庙人在岔路口喊过一句「别走」，也就到那儿了。一座坛场要真想留人，用不着这么费事。他们要的从来不是他这个人，是账上那一行字。

反过来也一样。他们不追，说明要的那行字已经写完了。写完了，就不必再留人。

这个道理他昨天就该想通。想通这一步的时候，膝盖已经在石阶上睡过一夜了。

跛脚人从山道上下来。

他一手拄着桃木棍，一手攥着一个布包，走得急，包角支出一截纸。看见沈念，他站住了。

「先生。」

沈念没有伸手。「那是什么。」

「守庙的给的。」跛脚人喘着气，「他说俺引了四十年的路，够本了，送俺一程。这一程就是把这包送到山门口。」

「你答应了。」

「俺……俺没说不送。」

沈念往他侧面挪了半步。

「包给我看一眼。」

跛脚人犹豫了一下，把布包递过来。

里头是黄纸，二十来张，每张画着墨线，线中间一个字一个字。纸边用蜡封过，暗红，指头一捏就碎。

沈念抽出一张，举到日头底下。

纸透光。帘纹一条一条竖着，间距很匀。

第二样对上了。

三样都是这个纸。这观里的签、像身上的账、跛脚人手里的符，全是一处发下来的。

「先生看出啥了。」

「符，签，账纸，是一处发下来的。」沈念把符折好，推回布包里，「你拿的是工钱。工钱记一笔，记完了有人来收。收的不是你引走的那个，是你。」

跛脚人的脸僵住。

「收俺？」

「收你引走的那个。」

「俺引了四十年，俺害了四十年。」跛脚人的手抖了一下，布包掉在地上，纸角散开，「俺闺女就是被人引走的。」

「所以你更不能把这包送到。」沈念说，「送完了，你就成了记上的那个。」

跛脚人弯腰去捡包，手一滑，纸撒了一地。

沈念没有再劝。他从跛脚人身边走过去，脚步比刚才快。

走出十几步，他回头喊了一句。

「老丈。」

跛脚人蹲在地上捡纸。

「那包东西你爱怎么处置就怎么处置。」沈念说，「别回头。」

他往山下走。

道上的赶路人多起来。挑担的、推车的、牵骡子的混在一处，谁也不看谁。他夹在里头走了一段，忽然停住。

回头看那道坡。

坡上一个黑点。没人下来。

也许那些东西真是他看错了。灰面是自己平的，像是自己摆的，符跟案上的纸也许不是一处发的。这地方兴许就是个断了香火的坛场，几个没着落的人守着几只空案子混饭吃。守着，像他也在守。

风把浮土卷起来，打在他鞋面上。

袖子里那张签贴着胸口。

事成之日，自有记号。

记号还没出来。册上那一行还在。册子认的是账，不认人。

赌不得。

沈念加快脚步。

客店里人还没散。

顾长风坐在院里的石凳上抽烟，裴昀拿一根草棍在砖缝里逗蚂蚁。小玉和三个少年在屋檐下睡午觉。

「先生回来了。」小玉一下坐起来。

「收拾东西。」沈念说，「走。」

「往哪儿。」

「往东。」

顾长风把烟锅在鞋底磕了磕：「往东是临川市。」

「嗯。」

「回临川市？」顾长风不动，「我们从临川市出来，就是不想回去。」

「不是回。是去米行街。」

顾长风看了他一会儿，把烟锅别回腰后。

「那个记路的白袍姑娘呢。」他忽然问。

「不见了。」沈念说，「五里铺那天，她一个人先走了，说要往北去。我找过，没找着。」

北边。

沈念记下这两个字，没往下问。一个人要走，走得比他干净，这话他信。

「先生，」裴昀站起来，「俺的米还没送到米行街。」

「你的米送到米行街，你妹妹就得上台。」沈念说，「你爹卖给她的价，比卖你还便宜。」

裴昀手里的草棍掉了。

「那就走。」他说。

后院的门响了一声。

跛脚人回来了。他一手拄着桃木棍，另一只手空着，桃木剑也不见了。

「俺把包撕了。」他说，「撕成片，埋在山道边那块石头底下了。」

「剑呢。」

「剑也埋了。」跛脚人把空的那只手翻过来，掌心里一道新磨出来的印子，「那把剑里头是刻符的模子，蜡也在里头。俺这四十年一直背着它，俺以为俺背的是个辟邪的。先生，俺背的是个印戳。」

沈念没有说话。

「先生，那俺算个什么。」

「你算一个引错路的。」沈念说，「引错路和引对路的人，价钱不一样。」

跛脚人站在那儿，肩膀塌下去一截。

顾长风叫人套车。戏箱上车，油布蒙好。板车吱呀吱呀地往山门外去。

走到坡下那个岔路口，小玉回头望了一眼。

山门很小，一个黑点。坡上没有人下来。

一队人从坡上下来。

远远的，看不清，走的是官道。

沈念把鞭子往驴屁股上抽了一下。
